## Meetings and audio

- Keep recording through brief transcription or network drops instead of ending the meeting
- Capture macOS system audio from whichever output the meeting app is using
- Skip unnecessary echo cancellation when headphones are the active output
- Start scheduled and ad hoc recording more reliably through microphone and browser-state changes

## Speakers and transcripts

- Keep manually assigned speaker names through live transcript updates and listening restarts
- Separate speakers during on-device batch transcription and when several people share one microphone
- Search transcripts by keyword

## Local workflow

- Organize notes in nested folders and sort the sidebar by date or folder
- Add local PDFs and reference files to folder-specific chat context
- Choose an existing whisper.cpp model file for on-device transcription
- Edit existing dictionary entries in place

## Reliability

- Open large encrypted local databases without a long migration stall
- Retry temporary provider rate limits during segmented batch transcription
- Keep chat replies streaming and keep the chat open when a request fails
